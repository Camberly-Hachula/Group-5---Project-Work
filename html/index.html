About the Project

Our project explores how a recipe dataset and a simple algorithm can help users find vegan or vegetarian recipes that match their dietary and personal needs. We collect recipes from different sources and organise the information so that it can be used to search and filter recipes more easily.

To Give an Example

The user is hosting a vegetarian dinner party and forgot a guest has a soy allergy. The user now needs to find a suitable recipe that can be cooked in time, before guests arrive.
