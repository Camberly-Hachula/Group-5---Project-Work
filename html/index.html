About the Project

Finding good plant-based recipes that suit your needs can be difficult, especially when dealing with allergies. Our project explores how a recipe dataset and a simple algorithm can help users find vegan or vegetarian meal options that match their dietary and personal needs. We collect recipes from different sources and organise the information so that it can be used to search and filter recipes more easily.

To Give an Example

The user is hosting a dinner party for their vegetarian friends, but remembers last minute that a guest has an allergy and now needs to rethink dinner plans. To solve this problem, the user takes help of our database and algorithm to quickly specify their needs, and find a recipe that can be prepared in time and all guests will be able to enjoy.
