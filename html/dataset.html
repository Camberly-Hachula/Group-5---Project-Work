About the Dataset

Our dataset contains vegetarian and vegan recipes collected manually from different online sources. Each recipe includes the dish name, dietary category, preparation time, allergen information and a link to the original recipe.

Why We Chose This Information

We selected these fields because they can help users find recipes that match their dietary needs and available time. We use the same structure for each recipe to keep the information organised and easier to compare.
