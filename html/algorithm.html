About the Algorithm

The aim of our algorithm is to help users find vegetarian and vegan recipes that match their needs. It will use the information in our dataset, including dietary category, preparation time and allergen information.

Design Choices

To showcase how information can be retrieved from our dataset using algorithms, two scenarios were created.

In the first scenario, the user wants a recipe which takes less than 20 minutes to prepare and does not contain eggs. This algorithm first uses the WRITE operation, prompting the user to specify these requirements thorugh input which is then interpreted by the algorithm using the READ operation. Next, the algorithm uses a counter (found = 0) which is necessary for recipes to be added to the result. The WHILE loop then goes on to check each recipe in the database through a linear search, and uses an IF clause to check if the requirements are met. This means that if a recipe meets the recipe's full record will be stated and added to the result list. Finally, an ENDIF command closes the IF statements once all recipes have been checked. Should no recipe fit the requirements, a "No recipes found" message will be displayed to the user.

In the second scenario, the user wants a recipe that avoids a certain allergen and takes less than 30 minutes to prepare. Similarly to the first scenario, the algorithm includes a WHILE loop containing IF statements. However, this algorithm has additional WRITE and READ commands, as the user is specifying more requirements compared to the previous scenario. This also means that the algorithm uses one more IF command to specify that this additional requirements needs to be checked with the dataset.

Explore Our Algorithm

Below you can explore the pseudocode for our recipe search algorithm.

Scenario 1:

WRITE “Which restriction?” (egg-free)
READ chosen_label
WRITE “Maximum preparation time in minutes?” (20 minutes)
READ max_time

found = 0
READ first recipe (recipe_ID, recipe_name, prep_time, dietary_labels)

WHILE recipe meets requirements
    IF dietary_labels contains chosen_label
        IF prep_time < max_time
            WRITE recipe_ID, recipe_name, prep_time, dietary_labels
            found = found + 1
        ENDIF
    ENDIF
    READ next recipe
ENDWHILE

IF found = 0
    WRITE "No recipes were found."
ENDIF

Scenario 2:

WRITE “Which dietary category” (vegan)
READ chosen_category
WRITE “Which restriction?” (soy-free)
READ chosen_label
WRITE “Maximum preparation time in minutes?” (30 minutes)
READ max_time

found = 0
READ first recipe (recipe_ID, recipe_name, prep_time, dietary_category, dietary_labels)

WHILE recipe meets requirements
  IF dietary_category = chosen_category
        IF dietary_labels contains chosen_label
            IF prep_time < max_time
                WRITE recipe_ID, recipe_name, prep_time, dietary_category, dietary_labels
                found = found + 1
            ENDIF
        ENDIF
    ENDIF
    READ next recipe
ENDWHILE

IF found = 0
    WRITE "No results were found."
ENDIF
