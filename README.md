Recipe Finder

About the Project

Recipe Finder is a student project that explores how a structured dataset and a simple algorithm can help users find vegetarian and vegan recipes that match their needs.
Finding suitable recipes can be difficult when users need to consider dietary preferences, allergens and preparation time.
Our project aims to make recipe information easier to organise, search and compare.

Our Dataset

The dataset contains 55 vegetarian and vegan recipes collected manually from different online sources. 
Each recipe includes information to help users identify suitable meals.

The dataset includes:

*Recipe name
*Dietary category (vegetarian, vegan or both)
*Preparation time
*Allergen information
*A link to the original recipe

We checked the recipes for the following dietary requirements and allergen categories:

*Gluten-free
*Soy-free
*Dairy-free
*Egg-free
*Nut-free

The original recipe links allow users to access the recipes and consult the source information.

The Algorithm

The algorithm is designed to use the dataset to help users find recipes based on selected criteria, such as dietary category, allergen information and preparation time.
The project also considers what should happen when no recipes match the user's criteria.
In this situation, the algorithm may suggest adjusting the search, for example by allowing more preparation time.

The Website

The website provides information about the project, its dataset, the algorithm and the team.
It consists of four main pages:

*Home: Introduces Recipe Finder and the purpose of the project.
*Dataset: Explains how the dataset is organised and why the selected information is useful.
*Algorithm: Describes the algorithm and its intended functionality.
*People: Introduces the team members and their contributions.

Technologies Used

HTML – to structure the website.
CSS – to style the website.
XML – to organise the recipe dataset.
Pseudocode – to describe the algorithm's logic.
GitHub – for version control and collaboration.

Teamwork

We worked collaboratively throughout the project.
Team members took responsibility for different areas, including the dataset, algorithm, website development and project coordination. 
We communicated regularly and shared ideas and feedback throughout the process.

Project Purpose

The purpose of this project is to explore how structured data and a simple algorithm can be used to support recipe searching. 
It also gives us practical experience in organising data, describing algorithmic processes, developing a website and collaborating using GitHub.
